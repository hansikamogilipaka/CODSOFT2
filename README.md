# Tic-Tac-Toe AI Game

An AI-powered Tic-Tac-Toe desktop application developed using Python and Tkinter. The game uses the Minimax Algorithm with Alpha-Beta Pruning to create an unbeatable AI opponent with fast and smooth gameplay.

---

## Features

- Modern GUI using Tkinter
- Human vs AI gameplay
- Unbeatable AI opponent
- Optimized Minimax Algorithm
- Alpha-Beta Pruning for fast response
- Scoreboard system
- Restart and Exit buttons
- Smooth and responsive gameplay

---

## Technologies Used

- Python
- Tkinter
- Minimax Algorithm
- Alpha-Beta Pruning
- Artificial Intelligence
